# Amazon Sales Analysis (Python Project)

## Project Overview
This project analyzes Amazon sales data using Python.

The goal is to understand sales performance, product trends, and customer behavior using data analysis libraries.

The analysis helps to understand:
- Total Sales
- Top Products
- Category Performance
- Sales Trends
- Customer Insights

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn

## Dataset
The dataset contains:
- Product names
- Category
- Price
- Quantity sold
- Revenue
- Customer ratings

## Analysis Performed
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Category-wise sales analysis
- Top selling products identification
- Trend analysis using graphs

## Key Insights
- Certain categories generate highest revenue
- Top products contribute major sales
- Sales patterns change over time
- Customer ratings impact product performance

## Files Included
- amazon_analysis.ipynb
- amazon_sales_data.csv
- graphs.png

## Conclusion
This project provides insights into Amazon sales using Python-based data analysis and visualization.
